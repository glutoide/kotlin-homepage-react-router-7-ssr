# Repository Rules

Before substantive work:

1. Read `glutoide/project-memory/AGENTS.md`.
2. Read this repository's `PROJECT_HANDOFF.md`.
3. Verify the current repository state before changing implementation or verification claims.

## Local rules

- Preserve the assignment's pinned JetBrains reference commit and retained third-party licenses.
- Do not weaken SSR, hydration, responsive, visual-parity, or provenance verification merely to make checks pass.
- Keep portfolio claims tied to reproducible tests and the actual source tree.
- Never commit secrets, credentials, private session data, or unrelated personal material.
- Use a branch and PR for substantive changes.
- Update `PROJECT_HANDOFF.md` when status, blockers, verification, or the next action changes.
